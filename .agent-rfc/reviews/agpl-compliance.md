# Review — AGPL-3.0 compliance, and the files a public project needs

Design: `.agent-rfc/designs/agpl-compliance.md`. The owner decided on 2026-11-03 to keep AGPL-3.0 and asked
for the requisite files. A mapping of obligations to files, not legal advice.

**Built evidence:** `NOTICE`; the portal footer's notices and Source link (`portal/lib/legal.ts`,
`AGENTSMITH_SOURCE_URL`); the notice in `widget.js`; `LICENSE` and `NOTICE` in wheels;
`THIRD_PARTY_LICENSES.md` generated by `scripts/third_party_notices.py`; `SECURITY.md`, `CONTRIBUTING.md`,
`CODE_OF_CONDUCT.md`, the issue and pull-request templates; README's licence section; tests in
`scripts/test/test_agpl_compliance.py` and `portal/test/legal.test.ts`.

## Pass 1 — findings: 3

1. `declared-vs-enforced` — **Several comparison pages call Arize Phoenix MIT-licensed; PyPI says
   `Elastic-2.0`**, and `docker-compose.yml` starts it. It is a separate container, not combined with this
   code, but it restricts offering it as a hosted service, and a company deploying the stack should know.
   **Fix:** `NOTICE` and `THIRD_PARTY_LICENSES.md` name it, and a test holds both.
2. `validate-on-the-receiving-side` — **The first footer took `AGENTSMITH_SOURCE_URL` straight into an
   `href`**, so a bad value could be a `javascript:` link. **Fix:** `sourceUrl()` accepts only http(s), and
   `portal/test/legal.test.ts` holds it.
3. `run-the-gates-ci-lists` — **The `artifacts` gate refused the new root documents.** **Fix:** declared as
   reference documentation in `process-gates.json`, which is what the gate asks.
