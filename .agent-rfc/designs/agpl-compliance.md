# AGPL-3.0 compliance, and the files a public project needs

## Problem

The owner decided on 2026-11-03 to keep AGPL-3.0 and asked for the requisite files. Measured on `main`:

- **`LICENSE` is the full AGPL-3.0 text, and that is all there is.** No copyright notice names a holder
  anywhere in the tree. `pyproject.toml` names a person, and `TRADEMARK.md` covers only the marks.
- **§13 is unmet in the shape it matters.** The Ops Portal is a network service, and it offers no source.
  A company running a modified portal has nothing to change, because there is nothing to point at its own
  source. §5(d) asks interactive interfaces to show Appropriate Legal Notices; the portal's footer says
  only "made by Aqlaar".
- **`widget.js` is conveyed to browsers with no licence notice.**
- **A wheel carries no licence.** `pyproject.toml` declares the licence as text and packages no `LICENSE`.
- **Third-party licences are recorded nowhere.** Audited 2026-11-03 across `requirements.lock`, the
  portal's and the widget's lockfiles: all compatible (MIT, Apache-2.0, BSD, ISC, MPL-2.0, LGPL-3.0,
  and `caniuse-lite`'s CC-BY-4.0 data). Phoenix is **Elastic-2.0**, run as a separate container, not
  combined with this code, but restricted as a hosted service, and a reader should be told.
- **No `SECURITY.md`, `CONTRIBUTING.md` or code of conduct, and no issue or pull-request templates.**

## Approach

- **`NOTICE`:** copyright, the AGPL's own notice with its warranty disclaimer, where the source is, what
  §13 asks of someone running a modified copy, the separately licensed services, and the marks.
- **The portal's footer** shows the copyright, the licence, no warranty, and a **Source** link.
  `AGENTSMITH_SOURCE_URL` overrides the link, so someone running a modified portal meets §13 by setting
  it. The default is this repository.
- **`widget.js`** carries the notice in its header.
- **Wheels** carry `LICENSE` and `NOTICE`.
- **`THIRD_PARTY_LICENSES.md`**, generated by `scripts/third_party_notices.py` from the three lockfiles. A
  test fails when a pinned package is missing from it, or when a licence outside the reviewed list appears.
- **`SECURITY.md`** (private reporting through GitHub, what is in scope), **`CONTRIBUTING.md`** (contributions
  under the AGPL, a DCO sign-off, the repository's own gates), **`CODE_OF_CONDUCT.md`**, issue and
  pull-request templates.
- **README's licence section** says what the AGPL asks of whom.
- **`process-gates.json`** declares the four new documents as reference documentation, as the `artifacts`
  gate asks: they are standard files for a public project, not a second home for anything.

**Not done, and why:**
- **Per-file SPDX headers:** not required, and they would collide with the package rename that follows.
  `NOTICE` covers the tree.
- **`TRADEMARK.md`** names Bobby Rajagopal as owner of the marks. Who holds them is a legal fact, and the
  owner's to change.
- **This is not legal advice.** The copyright holder named is the owner's company, as he stated; whether
  rights were assigned to it is for counsel.

## Pillars

- P1 applies — `.agent-rfc/designs/agpl-compliance.md` records the audit and the owner's decision before the change.
- P2 applies — `portal/lib/legal.ts` holds the notice once, and `scripts/third_party_notices.py` generates the list rather than a second hand-kept one; no dependency added.
- P3 n/a — static text in a footer; no traced path.
- P4 applies — `scripts/test/test_agpl_compliance.py` and `portal/test/legal.test.ts` hold the notices, the source link and the licence list.
- P7 n/a — no model built from external data; the footer stays a server component with no `use client`.
- P8 n/a — no telemetry.
- P9 n/a — no agent code.
- P10 n/a — no model call.
- P11 applies — `portal/lib/legal.ts` accepts only an `http(s)` URL from `AGENTSMITH_SOURCE_URL`, so a bad value cannot become a `javascript:` link.
- P12 n/a — no secret is read; `AGENTSMITH_SOURCE_URL` is a public URL.
- P13 n/a — no gate changes.
- P14 applies — `.agent-rfc/fixtures/knowledge_graph.json` is regenerated for the new files.
- P15 applies — `scripts/test/test_agpl_compliance.py` fails on a licence outside the reviewed list rather than recording it silently.
- P16 n/a — text and a link; reverting the commit restores them.

## Levers

- `declared-vs-enforced` — a licence stated in the README is not a notice shown to a user; the footer and a test make it one.
- `single-source-of-truth` — the third-party list is generated from the lockfiles.
- `validate-on-the-receiving-side` — an environment value becomes a link only if it is an http(s) URL.
