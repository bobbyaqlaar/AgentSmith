# CI installed these inline as ranges ("mypy>=1.11,<2.0"), so every run resolved
# whatever was newest that day and no developer could reproduce the gate: an
# unpinned tool answers a slightly different question each time it is installed.

# make the gate deterministic — the tool version and the language level it
# targets are both stated rather than inherited from the machine.
#

# smaller than a gate whose result depends on the date. Bump deliberately, run
# both gates, and commit the result.
